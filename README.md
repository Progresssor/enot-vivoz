# Енот Вывоз

Сайт вывоза строительного мусора в Москве и Московской области.

- `index.html` — весь сайт (одна страница)
- `*.webp` — картинки: еноты и контейнеры
- `CONTENT.md` — утверждённые тексты и функции
- Карты: Яндекс.Карты JavaScript API (ключ в `index.html`, переменная `YANDEX_MAPS_KEY`)

Публикация: Vercel, без сборки (статический сайт).
